Rationale

The primary is a deep programme green at 10.6:1 on white, dark enough to stay readable on a cheap LCD at half brightness outdoors. Gold carries waiting and due states because it reads as time passing rather than danger, and it never carries text below 7.6:1 — the bright gold is a fill only. Terracotta, taken from highland building clay, carries stalled cases: it signals intervention without borrowing the alarm of red. Red is reserved for referrals that actually failed, so a failed placement still stands out on a screen that has other colour on it.

Archivo pairs with Noto Sans Ethiopic because the two share a wide, low-contrast skeleton, so a bilingual table does not change weight when the language changes. Ge'ez runs at 1.75 line-height against Latin's 1.5.

Rejected: a blue primary, which reads as generic government software and clashes with the gold; the Ethiopian flag palette used literally, which makes a case management tool look like a state banner; woven pattern behind content, kept instead to the empty state and to nothing that sits under data; and any status signalled by colour alone — every chip carries a mark and a word, so the design survives a monochrome screen and a colour-blind reader.

Personal data is masked by default. Phone numbers show only the last four digits until a case manager taps Reveal, which is the shared-office case: a supervisor can read a caseload over someone's shoulder without collecting numbers.
